About Rest Client

Rest Client is an Android application that provides users with tools to make and work with REST API requests.

REST API Requests

Create and send HTTP requests to REST APIs and inspect the returned responses.

Easy to Use

A straightforward interface designed to make API testing convenient on Android devices.

Android App

Rest Client is available for Android users through Google Play.

Google Sign-In

Authentication

Rest Client provides Google Sign-In as an authentication option for users who choose to sign in with their Google account.

Google Sign-In is implemented using Firebase Authentication. Authentication is used to securely identify users within the application.

Rest Client does not require users to create a separate password for Google Sign-In.
